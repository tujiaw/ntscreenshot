## Global Constraints

No added cloud services or dependencies. Failed writes retain edits and existing files. Delete uses the recycle bin without permanent-delete fallback. Chinese and English documentation remain consistent.

## Review Focus

- Export while dirty must preserve both history directions and current selection.
- Cancel or failed export must leave pixels and state intact.
- Export to the source path must remain rejected.
- Transparency and output dimensions must apply only to the exported copy.
- Animation frame export must retain explicit frame-editing behavior.
