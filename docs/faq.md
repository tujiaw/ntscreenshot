# 常见问题

[English](faq.en.md)

## 从哪里下载？怎么安装？

打开 [GitHub Releases](https://github.com/tujiaw/ntscreenshot/releases)，下载最新的 `ntscreenshot-x64-Release.zip`，解压后运行 `ntscreenshot.exe`。不需要安装程序，也不需要管理员权限。

若页面上还没有附件，仓库目前只提供源码，请按 [构建指南](building.md) 在本机编译。请只从本仓库的 Releases 获取二进制，不要使用来路不明的网盘包。

## 为什么杀毒软件报警？

便携版是自行构建的 Qt 程序，没有购买商业代码签名。Windows Defender 和部分国内杀毒软件可能把未签名的新程序标成「未知」或「潜在风险」。这通常是启发式误报，而不是确认的病毒结论。

建议：

- 只从本仓库 Releases 下载
- 在 Windows 安全中心提交该文件进行检测
- 不要关闭整个实时防护来「解决」误报

## 按 F5 / F6 没反应？

常见原因：

- 程序没有在运行（看系统托盘）
- 快捷键被游戏、驱动或其它截图软件占用
- 以管理员身份运行的前台窗口会挡住普通权限进程的全局热键

到托盘 → 设置里改快捷键，或先退出其它截图工具再试。

## 启动后看不到窗口？

ntscreenshot 默认驻留托盘。关闭主窗口不会退出。在托盘图标上右键，可以打开主界面、设置或退出。如果重复启动后立刻退出，多半已经有一个实例在运行（单实例）。

## 安装包为什么这么大？

发布包会带上 Qt 和 WebEngine 运行库，体积明显大于「纯截图」小工具。这是为了标注、主题和可选的助手界面。若不需要 AI 助手，功能上仍可把相关项保持关闭，但当前构建仍会带上这些运行库。

## OCR 或二维码不能用？

二维码 / 条码识别走本地 OpenCV，截图选区后从右键菜单触发。OCR 需要在 **设置 → 图片** 中启用并配置服务。未配置时菜单会提示先开启。

## AI 会不会把截图传到你们的服务器？

项目不运营账号系统，也没有自己的云。只有你在设置里填写了第三方 API，并主动发起对话或工具调用时，内容才会发往**你填写的那个地址**。密钥写在本机配置文件里，目前没有额外加密，请使用可撤销的最小权限密钥。详见 [隐私说明](../PRIVACY.md)。

## 支持 macOS 或 Linux 吗？

当前只支持 Windows 10 / 11 x64。macOS 和 Linux 暂未提供。

## 数据存在哪？卸载怎么清理？

设置、日志、本地搜索索引在 Qt 应用数据目录中。Windows 上剪贴板历史默认在 `%LOCALAPPDATA%/ClipboardLite/history.db`。删除这些文件前请先退出程序。路径说明见 [隐私说明](../PRIVACY.md)。

## 如何反馈问题才不会被关掉？

请先搜索已有 Issue，并附上：系统版本、ntscreenshot 版本或 commit、能否稳定复现、脱敏后的日志。不要在公开 Issue 里贴 API Key、聊天记录或剪贴板内容。安全类问题走 [安全策略](../SECURITY.md)。
